# Observation timing study validation

AL-017's measurement protocol is frozen in
[decision 014](../architecture/decisions/014-observation-timing.md). Fresh PhysX
measurements and ideal-baseline reproduction are pending. Protocol tests alone
do not establish physical robustness or recovery acceptance.

The fixed matrix contains four timing profiles across seeds 0/1/2, with development
seed 73 excluded. It preserves the existing mission gates and original numerical
accuracy limitations. Measured results will replace this pending checkpoint after
all recordings have been independently verified.
